# 오늘의 숲

말을 모르는 AI들이 세 섬에서 매일 그림을 두고 말을 주고받는다. 통한 말만 살아남고, 새로 태어난 AI는 그 말을 절반만 물려받는다. 사이트 제목 자리의 '숲'은 매일 바뀐다.

- `engine/run.py` — 하루(한 세대)를 돌리는 프로그램. `DRY=1`이면 API 없이 흐름만 시험한다.
- `docs/` — 사이트(GitHub Pages). `docs/data/`에 모든 대화 기록이 쌓인다.
- `.github/workflows/daily.yml` — 매일 07:00, 19:00(KST)에 한 세대씩 돌린다.

API 키는 저장소 Secrets의 `ANTHROPIC_API_KEY`에만 있다. 코드와 기록 어디에도 키는 없다.

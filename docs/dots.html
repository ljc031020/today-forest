기존 섬선과 점 섬문자 표본

기말 실험 · 본 운영

점과 선만 주고, 모양부터 맡겼다.

기존 문자는 하나도 주지 않았다. AI들은 3×3 점 위에 선을 그어 글자를 만들고, 그림 맞히기로 뜻을 붙인다. 시험 10세대는 같은 조건의 섬 3곳을 따로 돌렸고, 11세대부터는 점 섬 3 하나만 이어서 돌린다. 규칙은 시험판 그대로 고정했다.

  • 획 = 점 두 개를 잇는 선 (예: 1–5)
  • 글자 = 획 1~4개, 말 = 글자 1~3개
  • 그림 맞히기 · 메모 30줄 · 하루 두 번(07시·19시) 세대 교체 · 옮겨 적기 실수 5% — 기존 섬과 같음
  • 지시문: 사람의 글자·숫자·기호나 사물 그림을 그리지 말 것
  • 11/12 확정 — 그림 글자도, 글자 이어 쓰기도 막지 않는다. 격자는 3×3 그대로. 디자이너는 규칙을 고치지 않는다.

서로 알아듣는 비율. 세대마다 32판 중 몇 판이 통했나.

점선 = 그냥 찍어도 맞히는 25% · 회색 띠 = 시험 운영(섬 3곳)

문자 한 벌. 점 섬 3이 지금 쓰는 서로 다른 글자.

글자 아래 = 이 글자가 들어간 말의 뜻 · 태어난 세대(지금 모양이 처음 나온 세대)

그림마다 지금의 말. 점 섬 3의 지금과, 시험이 끝난 10세대의 점 섬 1·2.

글자 아래 = 기존 문자 중 가장 닮은 글자와 닮음(0–1). 0.8 이상은 사람 글자를 거의 그대로 그린 것.

한 그림의 글자가 바뀌어 온 길. 테두리 = 그 세대에 바뀜.

새로운가? 기존 문자 약 200자와 모양을 비교했다.
